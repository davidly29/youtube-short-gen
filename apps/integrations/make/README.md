# ShortLoop app for Make

Generated by `pnpm -F integrations build:make` from `src/make/app.ts`. Don't edit these files by hand: the tests fail
when they are out of date.

In Make → **Custom apps** → _Create a new app_ (name `shortloop`, label `ShortLoop`), paste each file into the
matching block:

| File                          | Where in Make's app editor                                                             |
| ----------------------------- | -------------------------------------------------------------------------------------- |
| `app.json`                    | App settings (name, label, description, version)                                       |
| `base.json`                   | Base                                                                                   |
| `connection.json`             | Connections → new connection `shortloop` (Parameters / Communication tabs)             |
| `webhooks/shortRendered.json` | Webhooks → new dedicated webhook (Attach, Detach, Communication tabs)                  |
| `rpcs/*.json`                 | Remote procedures → one per file (Communication tab)                                   |
| `modules/*.json`              | Modules → one per file (Communication, Static/Mappable parameters, Interface, Samples) |

In module files, `parameters` are the static parameters and `expect` the mappable ones.
