# TikTok Content Posting audit checklist (E8-03)

TikTok reviews every app that uses Direct Post (H-01). This is the checklist from TikTok's
[content-sharing guidelines](https://developers.tiktok.com/doc/content-sharing-guidelines) and the
[Direct Post reference](https://developers.tiktok.com/doc/content-posting-api-reference-direct-post), mapped to where
ShortLoop meets each item. Re-check it against TikTok's current page before filing the audit; TikTok updates it.

Code: the rules live in `packages/providers/src/tiktok/tiktok.ts` (`tiktokPostProblems`, `allowedPrivacy`,
`commercialLabel`, `declarationParts`), the form in `apps/web/app/(app)/publish/tiktok/form.tsx`, and the server
re-check in `apps/web/app/(app)/publish/tiktok/service.ts` (`postToTikTok`). Tests: `pnpm -F providers test tiktok`,
`pnpm -F web test tiktok`, `pnpm -F web e2e publish-tiktok`.

| #   | Guideline                                                                                                                          | How ShortLoop meets it                                                                                                                                     | Tested by                     |
| --- | ---------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- |
| 1   | Call `creator_info/query` before rendering the post page                                                                           | `tiktokPostPage` fetches it on every view, and `postToTikTok` fetches it again before posting                                                              | web unit, e2e                 |
| 2   | Show the creator's nickname (and avatar) so they know which account they post to                                                   | "Posting to {nickname} @{username}" card at the top of the form                                                                                            | e2e (`tiktok-creator`)        |
| 3   | If `creator_info` says the creator can't post now, stop and tell them                                                              | `spam_risk_*`, `reached_active_user_cap` etc. map to `TikTokCannotPost`; the page shows the message instead of the form                                    | providers unit                |
| 4   | Check the video duration against `max_video_post_duration_sec`                                                                     | `tiktokPostProblems` blocks longer videos with the limit in the message                                                                                    | providers unit                |
| 5   | Show a preview of the content being posted                                                                                         | 9:16 video player of the approved render                                                                                                                   | e2e (`tiktok-preview`)        |
| 6   | The user can write and edit the title (caption)                                                                                    | Caption field starts empty (placeholder only), up to 2,200 characters                                                                                      | e2e                           |
| 7   | Privacy: options come from `privacy_level_options`, shown as a dropdown with **no default**; the user must pick one                | Select starts on "Select…"; Post is disabled until one is chosen; the server refuses a missing or unlisted value                                           | providers unit, e2e           |
| 8   | Interactions (Comment, Duet, Stitch): none on by default; greyed out when `creator_info` says the creator turned them off          | Three checkboxes, unchecked; disabled with "off in your TikTok settings"; the server refuses switching on a disabled one                                   | providers unit, web unit, e2e |
| 9   | Commercial content disclosure toggle, **off by default**                                                                           | "Disclose video content" switch, off                                                                                                                       | e2e                           |
| 10  | When on, the user must pick "Your brand", "Branded content" or both before posting                                                 | Post disabled with TikTok's wording: "You need to indicate if your content promotes yourself, a third party, or both."                                     | providers unit, e2e           |
| 11  | Show the label the post will get: "Promotional content" (Your brand) / "Paid partnership" (Branded content, or both)               | `commercialLabel` text under the options                                                                                                                   | providers unit, e2e           |
| 12  | Branded content can't be private (SELF_ONLY)                                                                                       | "Only me" is disabled while Branded content is ticked (and cleared if it was picked); the server refuses it                                                | providers unit, web unit, e2e |
| 13  | Declaration before posting: "By posting, you agree to TikTok's Music Usage Confirmation" (+ "Branded Content Policy" when branded) | `declarationParts` picks the wording; both link to TikTok's pages                                                                                          | providers unit, e2e           |
| 14  | Explicit consent: nothing is posted without the user's action, and they see all settings first                                     | The user ticks the declaration and presses **Post to TikTok** themselves; no auto-posting, no scheduled TikTok posts                                       | web unit, e2e                 |
| 15  | Don't add promotional watermarks, logos or branding to the content                                                                 | TikTok pulls the stored render byte-for-byte from a signed URL of its own storage key (`PULL_FROM_URL`); nothing is re-encoded or overlaid                 | web unit                      |
| 16  | After posting, tell the user processing can take a few minutes                                                                     | Shown under the button and on the post row while TikTok processes; the status comes from `status/fetch`                                                    | e2e                           |
| 17  | Unaudited clients can only post `SELF_ONLY`, to private accounts                                                                   | Without `TIKTOK_AUDITED=1` only "Only me" can be picked and a banner says posts will be private                                                            | providers unit, web unit, e2e |
| 18  | Label AI-generated content                                                                                                         | "AI-generated content" sets `is_aigc`; forced on (and locked) when the Short uses realistic AI visuals or an AI voice, like YouTube's synthetic-media flag | providers unit, e2e           |
| 19  | Request only the scopes needed                                                                                                     | `user.info.basic` and `video.publish`                                                                                                                      | providers unit                |
| 20  | Pulled URLs must be on a domain verified in the developer portal                                                                   | Operator setup: verify the R2/media domain (see `docs/setup/tiktok.md`)                                                                                    | manual                        |

Before filing the audit, record a screen capture of the full flow on staging (connect → form → post → status), as
TikTok asks for one.
