## start
Agree the list subject and number of entries (3 or 5). Target 30–45 s.

## script
- Scene 1 hook: "Number 1 will surprise you" style promise, but make it true.
- One scene per entry, counting down, each with one concrete fact.
- Final scene reveals number 1 and the reason.

## visuals
For each entry use two scenes if needed: a `card` title (`image_provider: "card"`, prompt "#3 <name>") with no narration and `duration: 1.2`, then the illustrative image with narration. Caption style "pop".

## publish
Title format: "Top 5 <thing> ranked". Add sources for facts in the description.
