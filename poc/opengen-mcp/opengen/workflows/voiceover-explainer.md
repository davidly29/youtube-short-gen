## start
Same as faceless-story but `aspect_ratio: "16:9"`, length up to 180 s.

## script
Sections of 2–3 scenes each, with a one-sentence signpost at the start of each section.

## visuals
Use `caption_style: "minimal"`. Mix `card` scenes for section titles with generated images.

## publish
Preview, then return chapters (timestamps) computed from scene starts in the job output.
