# ShortLoop Python SDK

Make, approve and publish original YouTube Shorts from Python. Generated from the public API's OpenAPI spec
(`docs/api/openapi.yaml`); standard library only, Python 3.9+.

## Five-minute quick-start

1. In ShortLoop, open **Settings → Developer** and create an API key (`sl_…`, shown once).
2. `pip install ./packages/sdk-py` (from this repo until it's on PyPI), then:

```python
from shortloop import ShortLoop

sl = ShortLoop(api_key="sl_...", base_url="https://<your app>/api/v1")  # or SHORTLOOP_API_KEY / SHORTLOOP_API_URL

short = sl.create_short(topic="why octopuses have three hearts", length_seconds=30)
made = sl.wait_for_job(short["job_id"])  # holds each request up to 50 s on the server
print("watch it:", made["video_url"])

sl.approve_short(short["project_id"])  # only after a person has watched it
pub = sl.publish_short(short["project_id"], privacy="private")
print("on YouTube:", sl.wait_for_job(pub["job_id"])["url"])
```

The same flow is in [`examples/quickstart.py`](examples/quickstart.py):
`SHORTLOOP_API_URL=… SHORTLOOP_API_KEY=… python examples/quickstart.py "your topic"`.

## What you get

- One method per endpoint (`create_short`, `get_job`, `approve_short`, `publish_short`, `swap_visual`, `list_voices`,
  `list_caption_styles`, `estimate_cost`, `get_balance`, `get_trends`, `list_workflows`, `get_workflow`,
  `list_webhooks`, `create_webhook`, `delete_webhook`, `list_deliveries`, `get_open_api`), with keyword arguments
  and `TypedDict` results.
- `wait_for_job(job_id)` returns the finished job or raises `JobFailedError`.
- Errors are `ShortLoopError` with `status`, `code` and `message`; `429` is retried after `Retry-After`.
- Webhooks: `verify_webhook(raw_body, headers["ShortLoop-Signature"], secret)` or `parse_webhook(…)`.

## Tests

`pytest packages/sdk-py` or `python3 -m unittest discover -s tests -t .` (what CI runs, via `pnpm -F sdk-py test`).
The client code is generated by `pnpm -F sdk-ts generate`; don't edit `shortloop/_generated.py` by hand.
